# GenAI


## 🚀 Running the House Price Prediction App

### Installation
```bash
pip install -r requirements.txt
```

### Run the Application
```bash
streamlit run app.py
```

### Features
- **Train Model**: Load Delhi housing data and train a Random Forest model
- **Make Prediction**: Input house details and get instant price predictions

### Usage
1. Navigate to "Train Model" page
2. Click "Load Data & Train Model" button
3. Wait for training to complete
4. Go to "Make Prediction" page
5. Enter house details and click "Predict Price"
